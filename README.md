# LifeFlow / HemaPath IoT System

An end-to-end IoT blood inventory and logistics tracking system built with Node.js, Express, MongoDB Atlas, and a live web dashboard.

## Features

* **Real-time Telemetry:** Receives live sensor readings (temperature, humidity, weight) from IoT storage units.
* **Hospital Request Tracking:** Logs and manages urgent blood supply requests from external facilities.
* **Transfer Logistics:** Tracks active blood shipments in real time.
* **Live Dashboard:** Interactive web interface with a sidebar navigation system and automatic data fetching.

---

## Tech Stack

* **Backend:** Node.js, Express.js
* **Database:** MongoDB Atlas (Cloud)
* **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
* **Hardware (Upcoming):** ESP32 / Microcontroller C++ Telemetry Integration
